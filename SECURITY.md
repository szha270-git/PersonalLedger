# Security Policy

PersonalLedger may handle sensitive financial information.

## Reporting security issues

Do not disclose credentials, account information, real financial records, or exploit details in public GitHub issues.

If GitHub private vulnerability reporting is enabled, use that mechanism.

Otherwise, open a minimal public issue requesting a private contact channel without including sensitive technical details.

## Sensitive data

The repository must not contain:

- real financial statements;
- account or card numbers;
- authentication credentials;
- API keys or tokens;
- private signing keys;
- production secrets;
- personally identifiable transaction data.

Test fixtures must use synthetic or thoroughly anonymised data.

## Supported versions

The project is currently pre-release.

Until versioned releases are established, security fixes apply to the actively developed main branch.
